# About this wiki

This is a hobby project: a browsable, searchable wiki for Drayano's **Pokémon Rising Ruby** and **Pokémon Sinking Sapphire**, inspired by the [Platinum Renegade Wiki](https://fredericdlugi.github.io/platinum-renegade-wiki/) by Frederic Dlugi.

## How it is made

Everything on this site is generated by a small Python pipeline that lives in the [GitHub repository](https://github.com/StephenAlvin/RRSS):

1. `tools/parse_docs.py` reads the six documentation text files that ship with the hack (Pokémon, area, attack, evolution, item and gift/static changes) and turns them into structured data.
2. `tools/base_data.py` builds the vanilla Omega Ruby / Alpha Sapphire baseline (base stats, types, abilities, TM/tutor/egg moves, evolutions, held items, move data) from the [PokeAPI](https://pokeapi.co/) CSV tables, reconstructing Generation 6 values where later games changed them.
3. `tools/generate_site.py` merges the two, so every Pokémon page shows the hack's data with vanilla values alongside anything that changed, and writes the Markdown pages.
4. [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) turns the Markdown into this site.

Level-up moves come entirely from Drayano's documentation. TM/HM, tutor and egg moves are the vanilla ORAS lists plus the additions the documentation describes. Base stats, abilities and types are vanilla unless the documentation lists a change.

## Building it yourself

```bash
pip install -r requirements.txt
python3 tools/build.py        # fetch data, parse docs, download sprites, generate pages
mkdocs serve                  # preview at http://127.0.0.1:8000/
```
